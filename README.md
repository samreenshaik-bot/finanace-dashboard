#📊 Finance Dashboard UI

📌 Overview

This project is a Finance Dashboard UI built using HTML, Tailwind CSS, and JavaScript.

It allows users to view financial data, explore transactions, and understand spending patterns through a clean and interactive interface.

The goal of this project is to demonstrate frontend development skills, including UI design, state handling, and user interaction — without relying on any backend.

#🚀 Features

#📈 Dashboard Overview

Displays Total Balance, Income, and Expenses

Provides a quick summary of financial status

#📊 Data Visualization

Line Chart → Shows transaction trend over time

Pie Chart → Displays spending breakdown by category

#📋 Transactions Section
List of all transactions with:
Date
Amount
Category
Type (Income/Expense)

#🔍 Search functionality to filter transactions by category
👤 Role-Based UI (Simulated)
Viewer
Can only view data
Admin
Can see additional actions (Edit option in table)

#🔍 Insights Section
Displays useful insights like:
Highest spending category
🛠️ Tech Stack
HTML5
Tailwind CSS
JavaScript (Vanilla JS)
Chart.js (for data visualization)
